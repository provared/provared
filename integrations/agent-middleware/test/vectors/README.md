# AMW's published test data

The four JSON files in this folder (`keys.json`, `permits.json`,
`receipts.json`, `rotation.json`) are copied unchanged from the folder
`spec/test-vectors/` of the repository
https://github.com/agentmiddleware/agent-middleware at commit
`326341c`, the project Agent Middleware (AMW).

Where the licence comes from: that repository's top-level `README.md`
says "Apache 2.0 (gateway is Fair Source, FSL-1.1)", that is, everything
is under the Apache License 2.0 except its `gateway/` folder, and
nothing from `gateway/` is here. When this reader was written, the
repository's `LICENSING.md` was also named as placing these files under
the Apache License 2.0; it is a statement of licences, not code, and was
not read again for this note. Copyright in the files belongs to the
Agent Middleware authors; the Apache License 2.0 is in `../../LICENSE`.

They are test data only: the keys are AMW's fixed test seed, as its own
`README.md` says ("Test use only"). They are read as data by the tests
beside them. Apart from these four files and the two text files named
above (`README.md` and, as recorded, `LICENSING.md`), nothing from that
repository (no script, verifier or program) was read, copied or run.
