Provared

Try it in your browser

Two minutes, nothing to install. Evidence, not a verdict.

A person gives an office agent a permission with a limit on what it may spend. The agent places some orders and signs a receipt for each one. Then the free checker reads the record, as a stranger would, and says whether the agent stayed within its permission, and where it did not.

All of it happens in this page, in your browser. Nothing you do here is sent anywhere, and nothing is kept once you close the page. The people, the supplier and the orders are invented.

Finding out what your browser can do …

1. The permission

In the checker's own words, read from the signed permission:

It is signed with the library's development stand-in for a passkey: a key made in this page's memory a moment ago, which no person confirmed. Every permission it signs says "(development)" in the name of whoever signed it, and names the address http://localhost, which the format allows only for development. A real permission is signed by a person, with a real passkey on their own device. A name in a record is a label; only keys are checked.

    What this page does not do

    • It uses no seal. A seal, which gathers the receipts under one fingerprint, is signed with a third method (SLH-DSA) that no browser has yet, so a seal's third signature is not checked in any browser. The command-line checker checks it. The checker's answer still shows the record's top fingerprint, which a seal would sign.
    • No other party countersigns the receipts made here, so each shows only what the agent's side said.
    • Nothing here is time-stamped by an outside service.

    Next

    To make a record of your own on your computer, with Node.js 24.7 or later, or Python 3.11 or later:

    npm install provared
pip install provared
npx provared-check --sample

    Check any record in your browser with the checking page, which loads nothing from anywhere. The guide shows how to put an agent's actions behind the same check. If you do not write code, Provared in plain words explains it in three minutes.
